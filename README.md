# Mathieu Lengrand — Data Analyst Portfolio

Astro portfolio starter focused on three analytics projects:

1. Amazon Ads Performance Analytics — active
2. OCR Data Processing Pipeline — coming soon
3. Football Momentum Visualization — coming soon

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Astro.

## Production build

```bash
npm run build
```

Astro writes the static site to `dist/`.

## Before publishing

- Replace `site: 'https://example.com'` in `astro.config.mjs` with the final domain.
- Add LinkedIn and CV links when ready.
- Replace the decorative Amazon dashboard preview with a real screenshot if desired.
- Review the wording of the About section.

## Deployment

This starter is static Astro, so it can be deployed directly to Netlify from a Git repository. No Netlify adapter is required unless server-side/on-demand features are later added.
